# Tessil

End-to-end encrypted file transfer, built and hosted in the EU.
Files are encrypted in your browser; the key stays in the link and never reaches our servers.

- **Send** files, free, with or without an account
- **Receive** files from clients through portals
- **Collect** answers with end-to-end encrypted forms
- **From the terminal** or an AI assistant: `npx tessil`

Everything is open source under AGPL-3.0, so the claims can be checked:
[how to verify it yourself](https://tessil.app/verify) · [security](https://tessil.app/security)

| Repo | What |
|---|---|
| [tessil-web](https://github.com/tessil-app/tessil-web) | The web app; all encryption happens here |
| [tessil-api](https://github.com/tessil-app/tessil-api) | The server; stores ciphertext and metadata only |
| [tessil-cli](https://github.com/tessil-app/tessil-cli) | Command-line tool and MCP server |
